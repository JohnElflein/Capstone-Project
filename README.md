
## Global Non-Communicable Disease (NCD) Mortality: The Relationship Between Economic Development Healthcare Spending, and Urbanization, 2000–2021

### Overview

This project investigates how non-communicable disease (NCD) mortality
has changed across countries between 2000 and 2021 and examines how
economic development, healthcare expenditure, and urbanization are
associated with these changes.

### Data Sources

- World Health Organization (WHO)
- World Bank
- United Nations (UN)

### Tools

- SQL / DBeaver
- Python
- Tableau
- Git / GitHub

### Research Question

How has NCD mortality changed across countries between 2000 and 2021,
and how are economic development, healthcare expenditure, and
urbanization associated with these changes?
